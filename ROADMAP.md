## Что внутри по шагам

### 01. Описание проекта

Черновик карточки с источниками; чего нет в документах — в `missing_fields`, без выдумок.

### 02. База

PostgreSQL 16 с pgvector, SQL-миграции, пул соединений, health/ready. ADR: [0001](docs/adr/0001-agent-stack.md), [0002](docs/adr/0002-sql-migrations.md).

### 03. Модель и долгие задачи

Вызов модели за одной границей (`LlmClient`: таймаут и повтор). Пайплайн extract → generate → critique. Таблица `jobs`, синхронная `POST /cards` и асинхронная `POST /jobs` с идемпотентностью. Процесс в Temporal переживает рестарт воркера; сигналы approve/reject.

### 04. Контракт карточки

Pydantic-схема карточки и SEO-блока, ссылки на источники, `missing_fields`, уверенность. Разбор ответа модели, лечение невалидного JSON, точечный ремонт поля. Ниже порога уверенности карточка ждёт подтверждения человека.

### 05. Документы поставщика

`POST /documents/` → 202 и `document_id`. Разбор pdf по страницам, docx по абзацам, xlsx со строками спецификации без разрыва. Нормализация, чанки с перекрытием и метаданными. Статусы: `новый`, `разбирается`, `проиндексирован`, `отказ`. Пять выданных файлов в `data/`; необязательный объём — `data/bulk/`.

### 06. Поиск

Локальные эмбеддинги `google/embeddinggemma-300m`, HNSW, полнотекст по-русски, гибрид (RRF). Порог релевантности подобран замером. Характеристики хорошо ловит смысл; артикулы поднимает гибрид.

### 07. Карточка из контекста

`POST /generate-card`: поиск → контекст → генерация → проверка ссылок → критика → ожидание сигнала. Ссылка годится, только если фрагмент есть в базе и был в поданном контексте. Пустой контекст — пустая карточка без вызова модели.

### 08. Стоимость и метрики

Таблица `llm_calls` (токены, `Decimal`-стоимость, модель, `job_id` / `request_id`). Две модели: основная и дешёвая. `make metrics` / `make metrics-all` по эталону `golden_cards.json`.

### 09. Защита

Маскирование PII до промпта и до логов. Детектор инъекций: правила, затем дешёвая модель по помеченным; при недоступности модели — fail-closed. Фильтр карточки на выходе. Отчёт `security` в результате задачи. ADR: [0003](docs/adr/0003-runtime-and-safety.md).

### 10. Сдача

Прогон с нуля на чистых томах, карточки по всем выданным документам (включая инъекцию и неполную спецификацию), отчёт с метриками и стоимостью, README на подъём без вопросов автору.
