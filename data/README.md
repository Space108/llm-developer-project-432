# Документы поставщиков

Набор, на котором проверяется каждый шаг проекта. Документы синтетические: реальных
компаний, людей и контактов в них нет. Содержимое детерминированное, повторная генерация
даёт те же файлы.

| Файл | Что это |
| --- | --- |
| `blender_passport.pdf` | Паспорт изделия: описание и таблицы характеристик |
| `blender_kp.docx` | Коммерческое предложение: текст, прайс, контакты менеджера |
| `kettle_spec.xlsx` | Спецификация: строки «артикул → параметры» |
| `kettle_manual.pdf` | Паспорт изделия другого производителя |
| `boiler_scan.pdf` | Документ, полученный сканированием |
| `golden_cards.json` | Эталон для замера качества генерации |

Студент берёт эти файлы из корня репозитория
[hexlet-components/data-supplier-docs](https://github.com/hexlet-components/data-supplier-docs), там лежит побайтовая копия этой папки.
Она же выдаётся артефактом на странице проекта. Файлы кладутся в `data/` репозитория
решения и коммитятся, автопроверка ищет их там и сверяет содержимое с этой папкой.

Копии обязаны совпадать. Правка файла здесь без той же правки в компоненте краснит
проверку у каждого студента, и сверяет их `make check-starter-set`.

## Чего ждать

Это документы «как есть», а не подготовленные учебные примеры. В каждом из них своя
особенность, из-за которой наивный разбор даёт неверный результат — какая именно, вы
увидите, когда до неё дойдёте. Если на каком-то шаге результат выглядит странно, начинайте
с документа, а не с кода.

`golden_cards.json` понадобится только на шаге про наблюдаемость и метрики. До него его
можно не открывать — а лучше и не открывать, чтобы не подгонять генерацию под эталон.

## Набор для прогона на объёме

Пять документов проверяют умения, и мало говорят о том, держится ли разбор на потоке.
Для этого в том же компоненте есть папка `supplier-docs/` со ста однотипными документами
по десяти категориям товара:
[hexlet-components/data-supplier-docs](https://github.com/hexlet-components/data-supplier-docs/tree/main/supplier-docs).
Он необязательный, на приёмку не влияет и живёт отдельной папкой вроде `data/bulk/`.
